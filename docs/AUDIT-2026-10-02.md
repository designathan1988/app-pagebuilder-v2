# Audit of the Builder — 2026-10-02

The final audit, architecture review and single-source-of-truth pass over the application at **commit `51ef179`**
(`main`, identical to `origin/main` of app-pagebuilder-v2: 0 commits ahead, 0 behind). Every claim below rests on a
command or a photograph saved on this machine under `.cache/logs/audit/` (git-ignored); the scripts that produced them
are in `.cache/scratch/audit/`. Severity: **4** blocks the work or loses it, **3** grave, **2** a nuisance, **1**
cosmetic. "Confirmed" means reproduced; "probable" means read in the code or observed once without a full reproduction.

## Verdict

**Ready for end-to-end use: no** — a realistic sequence (style a link's `:visited` state, click a heading, change its
font size) makes the whole editor disappear (AUD-01), and the exported site is wrong at tablet and phone widths
because the CSS rule merging breaks the cascade (AUD-02).

Everything else is in good shape: the complete browser suite is green (2,537 of 2,537), 214 of 214 features run
through their main door in Chrome, 100,000 random commands undo back to the exact starting document, and the Journey 03
tasks complete without dead ends. The two blockers are narrow and each has a precise cause.

## Findings by severity

37 findings: **1** of severity 4, **5** of severity 3, **16** of severity 2, **15** of severity 1.

### Severity 4

**AUD-01 — The editor goes blank when a refused change belongs to a command whose name has placeholders.** Confirmed.
- Where: `src/core/store/store.ts:231-234` (`breachMessage`) and `:373` (`status.change.failed`) put
  `{ key: command.labelKey }` into the message without the label's parameters; for `style.set` the label is
  "Set {property} to {value}", and the formatter throws `Missing parameter "property"` while React renders the status
  bar. `src/main.tsx:59` only reports React's uncaught error; there is no error boundary anywhere in `src/`
  (`grep componentDidCatch|getDerivedStateFromError` finds nothing), so the whole tree unmounts.
- Steps: open `manifest/features/fixtures/aurora.json`; select Intro in Layers; Insert › Link; canvas toolbar State ›
  Visited; click Title in Layers (the State button still reads "Visited"); type 40 in Font size and press Enter.
- Expected: the change refused with words, the editor intact. Obtained: a blank window; incidents "commit style.set left
  a document the model refuses" ×2 and "React could not render: Missing parameter "property" in "Set {property} to
  {value}"". A reload brings the editor back with the document unchanged and the state still "Visited".
- Reach: the 10 undoable commands whose labels carry placeholders (`style.set`, `style.setSpacing`, `element.insert`,
  `element.setAttribute`, `page.setSetting`, `components.insertInstance`, `classes.moveInto`,
  `classes.applyToSimilar`, `design.applySuggestion`, `element.createNaturalChild`) blank the editor on any breach or
  handler throw.
- Root cause: introduced by `917a35b` (QA-LOG 32, the J1 fix that made refusals speak); made reachable by AUD-03.
- Evidence: `.cache/logs/audit/fotos/breaches-B4/02-depois.png` (blank), `.cache/logs/audit/journey/B5.json` (incident
  text, reload result).

### Severity 3

**AUD-02 — The export merges identical rules into a place that breaks the cascade: tablet and phone styles are lost.**
Confirmed.
- Where: `src/core/render/clean.ts:75` `mergeCssLines`, introduced by `d1bf89e` (QA-LOG 51, stage 6). A merged media
  rule is written where its first member stood, before the base rules of the later members; at equal specificity the
  later base rule wins.
- Steps: export Marina's saved study project (`jornada03/data/downloads/marina-project.zip`, opened through the project
  reader, format version 1) and open `index.html` in Chrome at 834 and 390 px.
- Expected (what the project stores, and what the canvas draws: `.cache/logs/audit/journey/M3.json`): sections 32 px
  side padding at 834 and 20 px at 390; the plans grid 2 columns at 834 and 1 at 390. Obtained: sections keep 64 px at
  both; the plans grid keeps 3 columns of 76 px at 390, buttons overflowing (`05-cascade-proof.json`,
  `fotos/export-cascade/04-plans-at-390.png`). The preview builds its page from the same `siteFiles`, so it inherits
  the defect.
- Measured effect (the Journey 03 fidelity script, unchanged method): 1440 86.2/80.6 % and 1180 84.9/79.4 % as in the
  study; **834 78.5/68.4 % (study 81.0/77.1)**; **390 70.7/63.0 % (study 75.0/72.2)** — a regression.

**AUD-03 — The style state stays on while the selection moves to an element that does not take it, and style writes go
there.** Confirmed.
- The State menu offers only the states of the selected element (Visited is offered for a link, not for a heading), but
  choosing a state and then selecting another element keeps it. Nine writers then produce a document the validator
  refuses: `style.set`, `style.setBorder`, `style.setShadows`, `style.setSpacing`, `style.setGridItem`,
  `style.setBackgroundImage`, `position.setMode`, `motion.setBehaviour`, `field.step` (phase 3, 515 occurrences in
  100,000 random commands; minimal sequences of 2–3 steps such as `view.setStyleState {state: visited}` →
  `style.set {property: justify-content}` on the page root).
- In the interface: AUD-01's steps. Same family (a command writing what its target does not take):
  `element.setLabelTarget` writes `labelFor` on a non-label (49 occurrences), `guides.create` without a position
  writes an invalid guide.
- Evidence: `.cache/logs/audit/03-C-random.json` (`minimal`), `journey/B1.json`, `journey/B4.json`.

**AUD-04 — Structure commands on component instances produce invalid documents, and the context menu offers them.**
Confirmed.
- Remove wrapper on an instance (`element.unwrap`), Move out of parent (P) on a part of an instance (`element.promote`)
  and Nest into previous on an instance (`element.nestIntoPrevious`) leave `componentPart` on elements outside any
  instance, or an instance inside another. In Chrome (`catalog` fixture): "“Remove wrapper” was not applied: its result
  would leave the page invalid, so nothing changed. The details are in Incidents." — the person learns nothing they can
  act on, and the incident count grows. Phase 3 sweep: 42 occurrences over every node of every fixture.
- Evidence: `journey/B2.json`, `fotos/breaches-B2/`, `03-F-structure.json`.

**AUD-05 — Exporting a project and importing it back loses the design tokens and every class no element uses.**
Confirmed.
- `brand-title`: `:root { --brand: #0b7f72 }` comes back as "rules not mapped (lines 31)" and the project has no token
  (so every `var(--brand)` loses its definition); `classes-title`, `site-colours`: `.accent` dropped; `catalog-variants`:
  the variant class `.plan--gold` dropped — silently (the import's notes say nothing of the classes). Structure and the
  declarations of used rules survive on all 39 fixtures.
- Evidence: `03-D-roundtrip.json`, `03-D-detail.json`.

**AUD-06 — H17 / J25 is still refuted: at 1280 × 720 the canvas gets 41–46 % of the window, not 50 %.** Confirmed.

### Severity 2

**AUD-07 — The document core executes DOM.** Confirmed. `src/core/render/render.ts` is a DOM renderer
(`PageRenderer` creates, patches and focuses elements; `scrollbarWidth()` at `:135-143` appends a probe to the global
`document.body`, contradicting its own header "it never reads a global document"); `src/core/import/markup.ts:13` and
`import.ts:1322` default to `new DOMParser()`. The rule "no React, no DOM, ports injected" is enforced only for React
imports (`eslint.config.js:115-130`); the app tsconfig gives `src/core` the DOM library.

**AUD-08 — The store has three robustness gaps.** Confirmed by probe and code; reachability through the interface not
shown (the inspector disables the fields in the first case), probable through the assistant and MCP, which call
commands with model-made arguments.
- `store.ts:363` throws when a predicate refuses with a key the command does not declare — outside the handler's
  try/catch, so nothing is said. Nine style commands share `editableSelection` without declaring
  `status.locked.byAncestor`: `style.setSpacing`, `setBorder`, `setRadius`, `setBackgroundImage`, `setShadows`,
  `setFilter`, `setTransform`, `setCustomDeclarations`, `style.reset` (`03-E-locked.json`).
- `store.ts:440-443` adds a gesture's patches to the gesture before `commit` validates them (`:465`); in production
  (`freeze: false`) a refused commit inside a gesture leaves the refused patches in the gesture's history entry.
- `refusal()` / `canRun()` (`store.ts:490-501`) do not catch a handler that throws: 2,407 of the 8,178 bad-argument
  probes threw there (`03-B-bad-arguments.json`); with AUD-01's missing boundary, a control asking with stale
  arguments would blank the editor.

**AUD-09 — Handlers throw instead of refusing on references that do not exist.** Confirmed. 95 commands throw on stale
or malformed arguments (`guides.move` on a missing guide, `pages.switch` on a missing page, `tokens.rename` on an
unknown variable, 807 distinct signatures in the random run). The store turns a throw into "… failed and nothing
changed" in production; the project's rule is that predictable invalid operations are refused before any patch.

**AUD-10 — Security gaps known since the module handoff are still open.** Confirmed by code.
- `src/core/project/zip.ts:115-143` inflates every entry whole before comparing its declared size, with no total limit:
  a small archive that inflates to gigabytes exhausts the tab (File › Open project, Import HTML folder).
- `src/editor/shell/preview.tsx:37` accepts a key relay from any frame of the opaque origin, without checking that the
  source is the preview frame (`.memory/coordination.md` section B listed it as open).
- The read-only test port `__builderTestPort` ships in the production build (`.cache/user-build`), exposing the
  document to any script running in the editor's origin.

The six runtime cycles and how each breaks:

1. `style/set ↔ design/components ↔ structure/insert ↔ elements/table ↔ structure/duplicate ↔ style/couplings,
   recipes, tracks` (8 files): `set.ts` reads components to write instance-shared styles, while components insert and
   duplicate. Move the component lookups `set.ts` needs into the document layer (`document/components.ts`) and the table
   builders out of `structure/insert.ts`.
2. `files/files ↔ fonts ↔ references`: move the path helpers both read into `files/paths.ts`.
3. `document/validate ↔ page/settings ↔ render/output`: move the output model's types out of `render/output.ts`.
4. `workspace/layout ↔ workspace/panels`: extract the shared panel types.
5. `code-panel ↔ explorer`: move `generatedScripts` into `explorer/generated.ts`.
6. `data/panel ↔ shell/sidebar`: register the data view through the body table as the modules do.
A `no-circular` rule (dependency-cruiser) keeps them broken.
